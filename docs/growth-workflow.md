# Growth Workflow

## Positioning

WorkWise Tools should grow as a workflow-first AI tools publisher, not as a generic "largest directory" clone.

- Primary audience: US and UK small businesses.
- Primary content unit: workflow kit.
- First clusters: ecommerce sellers, marketing agencies, real estate agents, consultants, and sales teams.
- Monetisation priority: display ads first; affiliate and subscription ideas stay secondary until traffic proves repeat demand.

## Workflow kit standard

Each priority kit should connect:

1. A profession or use-case hub.
2. A workflow guide.
3. A comparison page.
4. An alternatives page.
5. A prompt or template page.
6. A free planner/checklist.
7. Country context only when wording, privacy, pricing, or terminology genuinely changes.

Do not publish a page just because a slug can be generated. Publish when the page has a unique decision angle, practical workflow detail, and internal links into the cluster.

## Weekly loop

1. Review Google Search Console.
2. Find pages with impressions and low CTR.
3. Improve titles, meta descriptions, and intro verdicts.
4. Find queries that deserve new pages.
5. Add internal links to pages gaining impressions.
6. Refresh any page with stale pricing or weak recommendations.
7. Add new tools/categories if search demand appears.

## Publish cadence

- Publish 10-20 useful pages per week when data quality allows.
- Advance 1-2 clusters at a time instead of scattering pages across unrelated categories.
- Prefer improving pages with impressions over creating speculative new pages.
- Keep exact pricing conservative unless the vendor page has been checked and `lastCheckedAt` is updated.

## Monthly loop

1. Add new AI/SaaS tools.
2. Update pricing and feature data.
3. Create new comparison pages from tools users search together.
4. Add new alternative pages where users show switching intent.
5. Review noindexed pages and improve or delete them.
6. Publish one linkable asset/report.

## Display ads readiness

Before applying to an ad network:

- Confirm Search Console and analytics are working.
- Keep zero thin indexable pages.
- Keep editorial, disclosure, contact, and review-method pages live.
- Add ad slots conservatively so guides remain readable.
- Add `ads.txt` only after the ad network supplies the publisher ID.

## Expansion loop

When a profession page starts getting impressions:

1. Add a prompt page for that profession.
2. Add a workflow page for that profession.
3. Add a country-specific version if relevant.
4. Add tool comparisons for the tools on that page.
5. Add alternatives for the top tools.
6. Add a free tool or calculator for the primary task.

## Refresh rules

Refresh high-value pages every 30–60 days:

- Best tools pages
- Alternatives pages
- Comparison pages
- Pages with affiliate clicks
- Pages ranking positions 4–20
- Pages with rising impressions but low CTR

Refresh lower-value pages every 90–180 days.

## Noindex/delete rules

Noindex or merge pages that have:

- insufficient matching tools
- no unique value block
- duplicated search intent
- zero impressions after a reasonable crawl window
- outdated or unverifiable information
