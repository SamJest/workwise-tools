# Launch Checklist

## Technical

- [ ] App builds without errors.
- [ ] Dynamic routes render valid pages.
- [ ] 404 pages work.
- [ ] Sitemap exists.
- [ ] Robots.txt exists.
- [ ] Canonicals are correct.
- [ ] Noindex is applied to thin pages.
- [ ] Metadata is unique per page type.
- [ ] JSON-LD is valid structurally.
- [ ] Images have alt text.
- [ ] Core pages are mobile-friendly.
- [ ] Forms have validation.

## Content

- [ ] All seed data marked as demo until verified.
- [ ] No fake reviews.
- [ ] Pricing notes include last checked date or verification warning.
- [ ] Affiliate disclosure is visible.
- [ ] Editorial policy is published.
- [ ] How-we-review page is published.
- [ ] At least 3 unique value blocks per indexable PSEO page.
- [ ] FAQs are useful and not keyword-stuffed.

## SEO

- [ ] Search Console configured.
- [ ] Analytics configured.
- [ ] Sitemap submitted.
- [ ] Important pages internally linked.
- [ ] Homepage links to main clusters.
- [ ] Category pages link to child pages.
- [ ] Breadcrumbs are implemented.
- [ ] No duplicate title patterns on core pages.

## Monetisation

- [ ] Affiliate links are centralised.
- [ ] Sponsored placements are disclosed.
- [ ] Newsletter capture works or is clearly staged.
- [ ] Vendor inquiry CTA exists if needed.
- [ ] No monetisation claims are fabricated.

## Post-launch

- [ ] Review indexing after 7–14 days.
- [ ] Review Search Console query data weekly.
- [ ] Improve pages with impressions but low CTR.
- [ ] Expand only from proven clusters.
