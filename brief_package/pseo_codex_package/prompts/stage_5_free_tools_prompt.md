# Stage 5 Codex Prompt — Free Tools MVP

Build lightweight free tools that support SEO and lead capture.

## Tools to build

1. AI Tool Recommender Quiz
2. AI Proposal Outline Generator
3. AI Cold Email Generator
4. Prompt Generator by Profession
5. SaaS Cost Calculator

## Requirements

- No paid external API required.
- Use local rule-based generation.
- Inputs must be validated.
- Outputs must be useful and copyable.
- Each tool must link to relevant guides and tools.
- Each tool must include a newsletter/email CTA placeholder.
- Each tool must have SEO metadata.

## Routes

```txt
/free-tools/ai-tool-recommender/
/free-tools/ai-proposal-generator/
/free-tools/ai-cold-email-generator/
/free-tools/prompt-generator/
/free-tools/saas-cost-calculator/
```

## Acceptance criteria

- Forms work.
- Outputs are generated instantly.
- Related content is shown.
- Components are accessible and mobile-friendly.
