# Stage 1 Codex Prompt — Foundation MVP

Build the foundation MVP for a database-driven AI/SaaS PSEO platform.

## Objective

Create the base Next.js app, design system, routing skeleton, seed data, reusable components, and technical SEO foundation.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL-ready setup
- Seed JSON fallback for local development

## Deliverables

1. Base app layout
2. Homepage
3. Header/footer/navigation
4. Tool cards
5. Comparison table component
6. Pros/cons component
7. Verdict box
8. Affiliate disclosure
9. Author box
10. Last updated component
11. Breadcrumbs
12. Related links module
13. Basic route groups:
    - `/ai-tools/`
    - `/professions/`
    - `/countries/`
    - `/comparisons/`
    - `/alternatives/`
    - `/workflows/`
    - `/prompts/`
    - `/templates/`
    - `/free-tools/`
14. Static policy pages:
    - `/about/`
    - `/editorial-policy/`
    - `/how-we-review-ai-tools/`
    - `/affiliate-disclosure/`
    - `/contact/`
15. Sitemap and robots.
16. JSON-LD helper.
17. Seed data loader.
18. README with setup instructions.

## Acceptance criteria

- App runs locally.
- Routes render cleanly.
- Components are reusable.
- Seed data appears in at least one list page.
- Sitemap and robots are available.
- No fake claims are presented as verified.
